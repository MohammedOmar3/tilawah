# Plan 03: Go API Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single Go service that does clock sync over WebSockets, counts listeners in memory, publishes a privacy-safe cached presence snapshot, and collects sync telemetry, while sending as few bytes out as possible.

**Architecture:** Modular monolith under `apps/api/internal/`. Every package takes a `clock.Clock` so tests never sleep. The WebSocket handler replies only to `hello` and `ping`. A background snapshotter rebuilds `presence.json` (plain and gzipped bytes) every `SNAPSHOT_INTERVAL` and the HTTP handler serves the pre-built bytes, which Cloudflare caches.

**Tech stack:** Go 1.24, `github.com/go-chi/chi/v5`, `github.com/coder/websocket`, `log/slog`, standard library otherwise.

**Owns:** `apps/api/` (except `Dockerfile`, which plan 07 owns).

**Spec sections:** §4.5, §4.6, §6. Privacy rules in `CLAUDE.md` are hard requirements.

```go
package clock

import ("sync"; "time")

type Clock interface{ Now() time.Time }

type Real struct{}
func (Real) Now() time.Time { return time.Now() }

type Fake struct{ mu sync.Mutex; t time.Time }
func NewFake(t time.Time) *Fake { return &Fake{t: t} }
func (f *Fake) Now() time.Time { f.mu.Lock(); defer f.mu.Unlock(); return f.t }
func (f *Fake) Advance(d time.Duration) { f.mu.Lock(); f.t = f.t.Add(d); f.mu.Unlock() }
```
