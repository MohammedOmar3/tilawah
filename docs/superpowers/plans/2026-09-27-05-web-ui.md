# Plan 05: Web UI and Integration Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The page a listener actually sees: what's playing, the current ayah in Arabic, how many are listening and from how many countries, the globe, and a Join button that drops them into the synchronized recitation. Plus the privacy page, the `/lab/audio` diagnostic page, accessibility, and end-to-end tests against the real API.

**Architecture:** One static route (`/`) composed of small client components reading the listening store (plan 04) and a presence store fed by a poller. Data loaders validate every fetched file with the contracts' Zod schemas. The globe (plan 06) mounts via `LazyGlobe` after first paint. Playwright runs the real Go API and a static server over `out/` for e2e.

**Tech stack:** Next.js static export, React, Tailwind, Zustand, Zod, `next/font/google` (Amiri Quran), Vitest + Testing Library, Playwright + `@axe-core/playwright`.

**Owns:** `apps/web/app/` (except `app/lab/globe/`), `apps/web/components/`, `apps/web/lib/data/`, `apps/web/lib/config.ts`, `apps/web/e2e/` (except `globe.spec.ts`), `apps/web/playwright.config.ts`, `apps/web/.env.development`.

**Depends on (merged):** plan 02 (data files), 03 (API for e2e), 04 (`createListeningSession`, `useListeningStore`), 06 (`LazyGlobe`).

**Spec sections:** §1 (S3, S4, S6), §2 (D3, D4), §5.

### Task 11: End-to-end tests

**Files:** Create `apps/web/e2e/join.spec.ts`, `sync.spec.ts`, `a11y.spec.ts`, `privacy.spec.ts`

- [ ] **Step 1: Write the tests:**
  - **join.spec** — before joining, the surah name and "Live" status are visible and the Join button is enabled; after clicking Join, status becomes "Listening" within 5 s (S3 proxy), the store reports `status: "playing"`, and the count shows ≥ 1 within 5 s (S6). Leave → count returns to 0 within 5 s.
  - **sync.spec** — two browser contexts; in context B, `addInitScript` overrides `performance.timeOrigin` by +7000 ms (a skewed client clock). Both join, 20 s apart. Wait 20 s. For each page read `{ offsetMs, errMs }` from `window.__tilawah.store`: page B's offset is within 50 ms of −7000 relative to page A's, and both `|errMs| < 100`. Then force page A's audio 800 ms ahead via `evaluate` and assert it's back under 40 ms within 60 s without a seek (rate path). Then block the WebSocket for 10 s (`page.route` abort + `context.setOffline`), assert audio time kept advancing and status returns to "Listening".
  - **a11y.spec** — `@axe-core/playwright` on `/` (before and after join) and `/privacy`: zero `serious` or `critical` violations. Tab order reaches Join, the anonymous switch, the privacy link and the globe. With `reducedMotion: "reduce"`, the globe reports `data-autorotate="false"`.
  - **privacy.spec** — after joining, `context.cookies()` is empty; no request goes to any host except `localhost:3000`, `localhost:8080` and `fonts.gstatic.com` (none at runtime, since `next/font` self-hosts, so assert only the two local hosts).
