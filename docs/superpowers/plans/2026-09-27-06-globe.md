# Plan 06: Globe Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A calm, GPU-rendered 3D globe that shows aggregated listeners as hexbins, pulses gently for batched joins, rotates and zooms by mouse, touch and keyboard, respects reduced motion, and never blocks first paint.

**Architecture:** A data-driven React component: `<Globe presence={Presence} />`. It renders a `three-globe` object inside a React Three Fiber `<Canvas>`, with land drawn as hex dots from a pre-stripped Natural Earth file. Pure functions (cell → hexbin mapping, colour/height scales, pulse scheduling) are unit-tested; rendering is checked with Playwright on a lab page fed by fixtures. `LazyGlobe` wraps it in `next/dynamic` so three.js is a separate chunk.

**Tech stack:** React Three Fiber, `@react-three/drei` (OrbitControls), `three`, `three-globe`, Vitest, Playwright.

**Owns:** `apps/web/globe/`, `apps/web/public/globe/`, `data/sources/natural-earth/`, `apps/web/app/lab/globe/`, `apps/web/e2e/globe.spec.ts`.

**Spec sections:** §4.6, §5.5. Features C1–C8.

**Input:** `Presence` from `@tilawah/contracts` and `packages/contracts/fixtures/presence.example.json`. Plan 05 supplies live data later; this plan never fetches.

### Task 5: Globe component

**Files:** Create `apps/web/globe/Globe.tsx`, `apps/web/globe/useReducedMotion.ts`, `apps/web/globe/usePageVisible.ts`

- [ ] **Step 1: Implement** (`"use client"`):
  - `<Canvas dpr={[1, 2]} frameloop={visible ? "always" : "never"} camera={{ position: [0, 0, 320], fov: 45 }} gl={{ antialias: true, powerPreference: "low-power" }}>`.
  - Create one `ThreeGlobe` in `useMemo`: `.showGlobe(true).globeMaterial(new MeshPhongMaterial({ color: "#0b1320" }))`, `.showAtmosphere(true).atmosphereColor("#d4af6b").atmosphereAltitude(0.12)`, land via `.hexPolygonsData(land.features).hexPolygonResolution(3).hexPolygonMargin(0.4).hexPolygonColor(() => "rgba(160, 174, 192, 0.35)")` (land fetched from `/globe/land.json` once).
  - Listeners via `.hexBinPointsData(cellsToPoints(presence.cells)).hexBinPointWeight("weight").hexBinResolution(3).hexAltitude(d => heightFor(d.sumWeight)).hexTopColor(...)` and `.hexSideColor(...)` using `colourFor`; `.hexTransitionDuration(reducedMotion ? 0 : 1200)`.
  - Pulses via `.ringsData(...)`: each scheduled pulse is added at its `atMs` (a `setTimeout` per pulse, cleared on unmount) and removed after 2.4 s; `.ringColor(() => t => \`rgba(245,222,170,${1 - t})\`).ringMaxRadius(3).ringPropagationSpeed(1.5).ringRepeatPeriod(0)`.
  - `<primitive object={globe} />`, ambient + directional light, drei `<OrbitControls enablePan={false} minDistance={180} maxDistance={500} enableDamping rotateSpeed={0.4} zoomSpeed={0.6} autoRotate={autoRotateEnabled(...)} autoRotateSpeed={0.25} onStart={markInteraction} />`.
  - Wrapper `<div role="img" aria-label={...} tabIndex={0} onKeyDown={...} data-globe-state="ready|loading" data-autorotate={String(...)} data-frameloop={...} data-rings={activeRingCount}>`. The label reads e.g. "Globe showing listeners in 82 countries". Keyboard actions from Task 4 move the camera via the controls ref.
  - `useReducedMotion` reads `matchMedia("(prefers-reduced-motion: reduce)")` and listens for changes. `usePageVisible` tracks `document.visibilityState`.
